# Video Game Sales Analysis

## Project Overview

The Video Game Sales Analysis project focuses on analyzing video game sales data to understand market trends, sales performance, and customer preferences across different platforms, genres, publishers, and regions. The main objective of this project is to identify the best-selling video games globally and regionally, understand platform-wise and genre-wise sales distribution, examine sales trends over different years, and evaluate publisher performance. Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn are used for data cleaning, data manipulation, exploratory data analysis (EDA), and data visualization.

## Dataset Description

The dataset contains information about video game sales, including game rankings, game names, platforms, release years, genres, publishers, and sales figures from different regions. The sales data includes North America, Europe, Japan, and Other regions, along with total Global Sales. These details help analyze the performance of video games in different markets.

## Data Analysis

The analysis begins with loading the dataset using Pandas and performing data inspection to understand the structure, data types, missing values, and statistical summary. Missing values and duplicate records are examined, and necessary data cleaning and preprocessing steps are performed to prepare the dataset for analysis.

Exploratory Data Analysis is performed to identify the top-selling video games based on global sales and calculate total worldwide sales. Platform performance is analyzed to find which gaming platforms generate the highest sales and how sales are distributed across different platforms. Genre analysis is conducted to identify the most popular game genres and understand their sales performance across platforms and regions.

Publisher performance is also analyzed to identify publishers with the highest global sales and compare their performance across different regions. Regional sales analysis is performed to understand the contribution of North America, Europe, Japan, and Other regions to worldwide video game sales and identify regional gaming preferences.

## Data Visualization

Different data visualization techniques are used to understand the dataset and present meaningful insights. Histograms, box plots, bar charts, and stacked bar charts are used to visualize sales distributions, compare platform and genre performance, analyze publisher sales, and understand regional sales trends.

## Technologies and Libraries Used

Python is used as the main programming language for this project. Pandas and NumPy are used for data manipulation and numerical operations, while Matplotlib and Seaborn are used for creating graphs and visualizing sales trends. Jupyter Notebook is used as the development environment for performing data analysis.

## Conclusion

This project provides a detailed analysis of video game sales across different years, platforms, genres, publishers, and geographical regions. It helps identify top-selling games, popular gaming platforms, successful genres, leading publishers, and regional sales patterns. The analysis provides useful insights into the video game industry's market trends and sales performance through Python-based data analysis and visualization.
